Continuwuity is a Matrix homeserver written in Rust. It's the official community continuation of the Conduwuit homeserver that aims to maintain a stable, reliable implementation, improve compatibility and specification compliance, fix bugs and performance issues from the original Conduwuit, add missing features needed by homeserver administrators, provide comprehensive documentation and easy deployment options, create a sustainable development model for long-term maintenance, and keep a lightweight, efficient codebase that can run on modest hardware
